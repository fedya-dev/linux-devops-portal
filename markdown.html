2. Git команди за работа със сайтове

Основни команди

git add .
Добавя всички промени за commit
git commit -m "Perf: Optimize hero image size and add font-display swap"
Commit с описание на промените
git push
Качва промените в remote репото

Празен commit (за trigger на build/deploy)

git commit --allow-empty -m "Empty commit"
Създава commit без реални промени
git push
Качва празния commit
Кога се ползва: Когато искаш да trigger-неш build/deploy без да си променял файлове (напр. след промяна в CI/CD настройките).

Примерен workflow

# 1. Добавяш промените
git add .

# 2. Правиш commit с ясно описание
git commit -m "Perf: Optimize hero image size and add font-display swap"

# 3. Качваш в GitHub/GitLab
git push
Conventional Commits: Използвай префикси като Perf:, Feat:, Fix:, Docs: за по-ясна история.

4. Основен синтаксис на Markdown

Заглавия

# Заглавие 1 (H1)
## Заглавие 2 (H2)
### Заглавие 3 (H3)
#### Заглавие 4 (H4)

Удебелен и наклонен текст

**Удебелен текст**
*Наклонен текст*
***Удебелен и наклонен***
Резултат: Удебелен текст, Наклонен текст, Удебелен и наклонен

Списъци

## Неномериран списък
- Първи елемент
- Втори елемент
  - Поделемент (2 интервала + тире)
- Трети елемент

## Номериран списък
1. Първи
2. Втори
3. Трети

Връзки и изображения

[Текст на връзката](https://example.com)
![Алтернативен текст](/path/to/image.jpg)

Цитати

> Това е цитат
> Може да има няколко реда
Това е цитат. Може да има няколко реда.

Хоризонтална линия (разделител)

Текст преди линията.

---

Текст след линията.
Важно: Винаги оставяй празен ред преди и след ---. Използвай точно 3 тирета, не повече!

5. HTML в Markdown (за Astro) – Оцветяване

Astro позволява HTML директно в Markdown файловете. За оцветяване използваш <span style="color: ...;">.

Как се оцветява дума – пълен пример

Това е 
<span style="color: red;">червена</span> дума.
Това е червена дума.

Оцветяване с hex код (препоръчително)

Това е 
<span style="color: #d32f2f;">тъмночервена</span> дума.
Това е тъмночервена дума.

Пълно изречение с оцветяване

<span style="color: #ff5d00;">Важно:</span> Този материал 
има <span style="color: #d32f2f;">информационен характер</span>.
Важно: Този материал има информационен характер.

Често използвани цветове с код

Цвят HTML код Пример
Червено <span style="color: #d32f2f;">текст</span> ■ Червено
Оранжево (Astro) <span style="color: #ff5d00;">текст</span> ■ Оранжево
Зелено <span style="color: #2e7d32;">текст</span> ■ Зелено
Синьо <span style="color: #1976d2;">текст</span> ■ Синьо
Сиво <span style="color: #757575;">текст</span> ■ Сиво
Златисто <span style="color: #f57f17;">текст</span> ■ Златисто

Комбиниране на стилове

<span style="color: red; font-weight: bold; font-size: 16px;">
Червен, удебелен и по-голям
</span>
Червен, удебелен и по-голям

Подчертаване на текст

Това е <u>подчертана</u> дума.

Или: Това е <span style="text-decoration: underline;">подчертана</span> дума.
Това е подчертана дума.

Изображения в Markdown

![LH3 кран – вътрешен вид](/images/kmd2.webp)
Формат: ![Алтернативен текст](път/до/изображението)
Важно за Markdown файловете: Когато пишеш HTML в .md файл, пиши го директно – не е нужно да ескейпваш < и >. Astro ще го разбере.

Как да използваш CSS класове (по-чисто за много оцветявания)

Ако ще оцветяваш често, дефинирай класове в CSS файла на Astro.
1. В CSS файла (напр. src/styles/global.css): 
.text-danger {
  color: #d32f2f;
}

.text-warning {
  color: #ff9800;
}

.text-success {
  color: #2e7d32;
}

.text-astro {
  color: #ff5d00;
}
2. В Markdown файла: 
Това е <span class="text-danger">червена</span> дума.

Това е <span class="text-astro">оранжева</span> дума.
Предимство на класовете: Променяш цвета на едно място в CSS и се обновява навсякъде в сайта.
Внимание: Не прекалявай с оцветяването! Използвай го само за акценти и важни предупреждения.

8. Бърза справка – най-често използвани неща

За ежедневна работа

  • Заглавия: #, ##, ###
  • Удебелен: **текст**
  • Наклонен: *текст*
  • Списъци: - или 1.
  • Връзки: [текст](url)
  • Изображения: ![alt](/path/to/image.webp)
  • Разделител: --- (с празни редове около!)
  • Оцветяване: <span style="color: red;">текст</span>

✍️ Git workflow

  • git add . – добавя промените
  • git commit -m "Описание" – commit
  • git push – качва в remote
  • gp "Описание" – Прави горните три
  • git commit --allow-empty -m "Empty commit" – Създава commit без реални промени

🛠️ Основни команди

  • npm run dev – Стартира локален сървър за разработка (http://localhost:4321)
  • npm run build – Изгражда сайта за продакшън в папка `dist/`
  • rm -rf .astro – Изтрива перманентно скритата папка за кеш

За SEO и метаданни

  • title – макс. 60 символа
  • description – 150-160 символа
  • tags – 5-8 тага на статия
  • heroImage – оптимизиран WebP формат

Размери на изображения

  • 1920 × 1080 px — 16:9 (TrainBrakes и други)
  • Винаги оптимизирай за web (WebP формат)
